# GitHub repo setup

Fill these in on your repo page (gear icon next to "About", top right).

**Description:**
```
See exactly what your AI agent did. Local tracing + a visual dashboard for debugging LangChain agent runs — no cloud, no API key.
```

**Topics** (add as tags — this is how people discover repos via GitHub search/browse):
```
ai-agents
langchain
observability
debugging
llm
developer-tools
typescript
agent-monitoring
llmops
```

**Website field:** your npm package page, once published (e.g. `https://www.npmjs.com/package/stepglass`)

**Also turn on:** Settings → Features → Discussions. Gives people a low-friction way
to say "I'm using this" without opening a formal issue — useful as citable evidence
of real usage later.

## After creating the repo

1. Add the description, topics, and website above
2. Create a new issue titled `Roadmap & adapter requests` using the content in
   `docs/pinned-roadmap-issue.md`, then pin it
3. Post the launches in `docs/launch-posts.md` once the repo and npm package are live
